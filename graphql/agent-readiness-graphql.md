# Agent Readiness GraphQL API

Reference provider with arguably the most extensively-tooled developer surface on the web. Public OpenAPI, GraphQL schema, webhooks, conditional requests, explicit `X-RateLimit-*` headers, status page, and an MCP server — a near-complete agent-readiness signal set.
